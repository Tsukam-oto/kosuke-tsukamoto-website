# 束元康介 公式サイト｜制作・組版・品質ルール

更新：2026-11-23／初版。正本はリポジトリの `main` にマージされた版。管理Issue：#79、組版 #80、自動検査 #81、既存ページ監査 #82。

## 目的
作品・歌詞・音源・制作背景に集中できるサイトを維持する。新規ページでも「改行がおかしい」「スマホで読めない」「直した箇所が戻った」を繰り返さない。
**公開ページ・コード変更は、明示的な作業範囲の指示がある場合のみ行う。** この文書は一括改修・本番更新を許可するものではない。

## 制作時に確認する順序
1. GitHub `main`、開いているPR、未完了Issues、既存ページ・CSSを読む。既存の改善を二重実装しない。
2. 対象の目的、優先情報、閲覧者の次の操作、保護対象を記す。原則として、ページを長くする前に重複を減らす。
3. 画面幅 320 / 375 / 390 / 430 / 768 / 1024 / 1440pxを設計に入れる。表示倍率200%、横画面も確認する。
4. 日本語組版、アクセシビリティ、リンク・音源・フォームの状態を実画面で確認する。
5. 修正した不具合は再発防止テストも追加し、関連IssueとPRに証拠を残す。
6. 本番公開が認められている案件は、マージ後も公開URLで再検証してからIssueを完了にする。

## 日本語とレイアウト
| 種別 | 基準 |
|---|---|
| 大見出し・キャッチコピー | 意味単位で折り返す。手動改行は明確な表現意図があるときだけ。変更前後の実画面を比較 |
| 作品名・副題 | 正式名称を一切変更しない。行末の孤立1文字、英単語の途中分割、長い助詞の分離を避ける |
| 本文・説明 | 本来の文章は原則として自然な改行に任せる。狭い幅での体裁を整えるためだけの `<br>` を使わない |
| 数字＋助数詞 | 「3つ」「第4番」「1st EP」など意味のまとまりが離れる候補を画面で確認 |
| ボタン・リンク | タッチターゲットは原則44×44px以上。文字が2行になっても切れず、意味が通る |
| 詩・歌詞 | **本文・原文改行・空行・句読点・作者名は不変**。狭幅の視覚的なソフト折り返しと原文改変を区別 |
| LYRIC BOX | 元データ、2作品抽選、既存2列表示、出典リンク、共有処理を保護。短文・長文・混在文を試す |
| 縦読み・仕掛け | 作者が設けた文字列や演出を維持。キーボードでの操作と狭幅表示も検証 |

- `white-space:nowrap`、`word-break:break-all`、`overflow-wrap:anywhere` は、便利だからという理由で見出し・作品名・詩に無差別適用しない。
- `text-wrap:balance` や禁則処理は、文字列の自然さを保証するものではない。**スクリーンショットで実際の折り返しを確認する**。
- 小さい補足情報と普通の説明文は別物。文字を極小にして行数だけ減らさない。文字拡大でも読める設計とする。
- CSSを継ぎ足す前に既存のセレクターと優先順位を確認し、不要な上書きを増やさない。

## ページと情報の役割
- **トップ**：作者と最新発表を知り、WORKS/LYRICS/EDUCATION/VOICE BOXへ進む表紙。指揮ビジュアル、4入口、SPECIAL THANKS、トップ2列LYRIC BOXを保護。重複する最新告知を増やさない。
- **WORKS**：ジャンル・曲名から探し、制作デモ、試聴抜粋、正式ライブを区別して聴く。次の作品へ迷わず進める。
- **詩集**：本文が主役。共有は補助。全篇の本文・空行・原文を保持。
- **EP**：「発表日」と「配信開始日」を混同しない。未確定の開始日を捏造しない。
- **VOICE BOX・応募・お問い合わせ**：内容の自動公開をしない。項目、匿名性、同意、入力保持、送信先を保護。許可のない実送信は行わない。
- 学校内部資料、個人情報、未確認の音源・譜面・権利関係を公開しない。

## 公開前の品質ゲート
状態は `PASS / FAIL / NEEDS_REVIEW / NOT_RUN` を区別する。
- 静的：公開URL、リンク/アンカー、画像、alt、見出し、メタ情報、コンテンツ/音源の原本整合。
- ブラウザ：Chromium＋WebKitで320〜1440px、横スクロール、文字欠け、ナビ、操作、表示倍率200％を確認。
- 自動化できない日本語の**意味上の不自然な改行は `NEEDS_REVIEW`**とし、実画面確認が済むまでPASS扱いしない。
- 変更箇所に対応する既存テストに加え、発見した問題の再発防止ケースを追加。
- 既存の `tests/first-single-ui.mjs` と `.github/workflows/first-single-ui.yml` は保護。全サイト共通QAは Issue #81 で整備する（現時点では未実装）。

## 2026-11-23に修正した再発防止例
- 11月22日のEP発表後、トップでEP告知が複数帯に重複しないよう、翌日以降はカウントダウン帯を隠す。
- 発表用ポップアップは発表当日の初回表示だけ。翌日以降の新規訪問者を遮らない。
- スマホのEP告知ボタンは44px以上を確保し、作品名の折り返しは語中の強制分断を避ける。
- 関連テストで11月23日の状態、320/390/1440px、水平スクロールなし、CTA表示を検証する。

## 今後の運用
- 質問や不具合をチャットに放置しない。重複Issueを調べ、既存Issueを更新または新規登録。
- 変更ごとに「どこを変更したか／何を保護したか／何を検証したか／未検証は何か」をPRに記録。
- **完成の判定は、レビュー用コード提出でも自動テストの成功だけでもなく、承認された公開作業と本番確認まで終えた時点**とする。
