# 1st Single 特設サイト デザイン v2（2026-11-05）
対象：『あなたと、これから、これからも』、2026-11-22 配信予定。販売ページとは別の体験とする。

## 旧案の問題と変更
- 旧案：深紺・真鍮色・3つの円。概念図が前面に出て楽曲固有の特徴が弱く、曲より先に説明文を読ませた。
- v2：曲名の日本語組版を主役にする。白・黒を基調に、強い青をアクセントとして使用。3つの円・ありがちな卒業演出・架空の音声波形を撤去。
- 題字、文字の反復、ピアノと本人の歌による新録という事実を画面の軸にする。デザインのために歌詞の意味を断定しない。

## 文言改訂 v2.1（2026-11-05）
- ファーストビューは「《あなたと》《これから》の新録と、新曲《これからも》を収録。」へ整理。配信予定日の確定情報以外は慎重に記述する。
- 「本人の歌とピアノで」「今度は」「かつて合唱だった」「作品に時間が重なる」「聴きたい人がすぐに聴けるように」など、説明的・感傷的なコピーを削除。
- 各曲の出自、版と新録の関係、正確なクレジットは、原資料と作者の確認があるところだけ短く掲載。新録の完了を未検証のまま断定しない。
- **サイトを分ける**：note＝発信・制作ノート（アカウント作成済み、記事URL未確認）、販売サイト＝楽譜/GAS等の購入・公費見積、公式サイト＝活動全体、配信特設＝1st Single。相互リンクは実在する公開先を検証してから設置する。
- 配信特設サイトの販売用カードを除去。配信先への導線を主とし、noteや販売の公開・リンク確認後に補助的な導線を検討する。
- 販売準備はPR #48等の独立作業で行い、配信特設サイトの本文修正に混在させない。PR #57は過去の共通計画用の下書きであり、本番へ無断マージしない。

## 情報設計：卒業生と一般の聴き手の両方に届く順番
1. ファーストビュー：正式タイトル・作家名・配信予定・3曲という最小情報。公開前は「3曲について見る」、配信確認後は実際の配信先への「聴く」を上位に。
2. 曲別詳細：01《あなたと》令和6年度卒業記念創作合唱の本人新録、02《これから》令和7年度の本人新録、03《これからも》新曲。事実確認ができる説明のみ。
3. 作品の背景：聴き手が自発的に読む領域。制作の記録は本人提供の言葉と確認済みの素材に限定。
4. 配信導線：実在するサービスリンクを検証後に挿入。有料ダウンロードと楽譜販売は控えめな別導線。
5. MV：制作・公開が確定してから表示。卒業生本人の参加、校内の写真・音声には任意の同意と権利確認が必要。

## 実装品質
- 375/390/1440px等の画面幅、横スクロールゼロ、文字折り返し・キーボード操作・focus-visible、prefers-reduced-motionを検査。
- 手元の v2 HTML はクリックで詳細開閉可能。歌詞・音源・購入・配信URLの模擬実行はしない。
- 一度許諾済み音源と正式ジャケットがそろった時点で、正式素材による再デザインを行う。CSS内のスクエアは**正式ジャケットではない**。
- 発売前後の表記は個別検証する。2026-11-22当日に自動で『配信中』と断定しない。

## 別プロジェクトの販売先行計画
- 既存 PR #48 で一般購入（BOOTH候補）＋学校公費購入（発行主体・書類・兼業・権利確認後）を整える。
- GAS体験版 PR #45 の実体はデモであり有料商品ではない。独立版と導入テストが必要。
- 販売開始前に法令/服務・権利帰属・著作者表示・販売者情報・決済と納品試験が必要。
- 価格等の既存案を勝手に変更しない。販売サイトとアーティスト作品サイトを混同しない。

## 既存の誤版の取り扱い
- 《あなたと》の現行Web掲載音源・譜例・歌詞に誤データの指摘があるため、本人による正本照合まで v2 ページへ流用しない。
- 作詞クレジットは公式ページ間の表記差がある。卒業生の関与と本人の寄与を一次資料で整理後に固定する。
- 在校生向けに購入を促す導線や、学校情報を用いた私的商業勧誘は作らない。

## 完成の判断
- 作者の音源と作品として説得力があること。
- 卒業生だけでなく、曲を知らない一般の聴き手も最小操作で曲へ進めること。
- 感動を約束する説明や卒業の美化でなく、作品と事実で支えること。
