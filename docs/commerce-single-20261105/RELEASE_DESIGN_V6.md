## 3曲の文章で意識した相違点
- 《あなたと》：卒業を前に、楽しいことも悔しいことも含めて振り返る。「この学校で良かった」。周囲への感謝と卒業後への不安。
- 《これから》：いつもの景色が最後になる切なさ。すれ違いも含めた仲間との時間、後輩へ受け継ぐ気持ち。「より良い学校を作るのは あなたの番だよ」。
- 《これからも》：「自分のこれから」を喜んでくれる人がいた。忘れても、つながりを煩わしく感じても、今から続く時間を考える。「この歌を目印に」。
- いずれも編集者による文章案であり、作者の最終承認前。卒業生を美化せず、結婚を3曲共通テーマとして扱わない。

## 情報源と確認条件
- 《あなたと》《これから》：作詞・作曲表記と歌詞をユーザーの詩集『音楽の風景』の4、7ページ（PDF上ページ4,7）で照合した。学校名は特設サイトに掲載していない。
- 《これからも》：ユーザーが2026-11-08に引き継いだ歌詞を元に引用。歌詞は改変せず、制作ノートはAIによる未承認案として区別する。
- **トラック順**：試作は01 あなたと→02 これから→03 これからも。過去の初回配信DBメモには「これから / あなたと / これからも」の順序が記録されているため、正式なリリース登録と照合するまで確定しない。
- **あなたとの原譜・音源**：過去の公開デモ・譜例に誤版の指摘がある。今回の作品紹介では旧音源・旧譜例を流用していない。
- **正式配信情報**：ジャケット、ISRC、リリース日時、URL、音源マスター、編曲・演奏・録音担当は未確認。この試作では外部配信リンクを生成しない。
- **販売とは独立**：音源の有料DL、GAS、楽譜販売に関するリンクを未実装。公開後も販売を優先するCTAは作らない。
