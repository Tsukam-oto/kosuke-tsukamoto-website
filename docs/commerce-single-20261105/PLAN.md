## 目標と先行順序
### A 販売可能な仕組み
- `scores/`：一般購入（BOOTH候補）と学校公費（直接見積）を区別。
- 価格案（税込）：ファンファーレ1,000円／吹奏楽小品2,000円／通常3,000円／合唱3,000円／スコア単品500円／音取り音源+1,000円は後続。
- 商品それぞれに：正式作品ID、出版版、収録PDF、ページ・パート数、楽器編成、試聴、権利確認、利用範囲、再ダウンロード、問い合わせ先、公開状態、最終更新日。
- 一般購入：BOOTHの本物の商品リンクを確認してから表示。サイト内に秘密鍵や決済情報を置かない。
- 公費購入：相談→見積→事前決裁→正式発注→PDF納品→請求／支払。見積・請求書の発行機能は認証付き私的領域またはローカルに置く。
- 商品例：ファンファーレ第4番《朝》は出版候補。ただしFinaleとの音高・音価照合、紙面試験、©Adachi01表記の権利確認が未了なので販売不可。
- GAS：学校で使っているコードをそのまま販売しない。個人Google環境に独立版、ダミーデータ、別アカウント導入検証、操作説明、サポート条件。
- 配信シングル購入版（仮700円）は別商品。音源配信とデジタル購入、楽譜販売を混同しない。

### B 配信特設サイト
- URL案：`/releases/2026-11-22/`（構想段階）。公式トップの最新作品から一歩でアクセス。
- デザインテーマ：作品の連続性を「一本の線」「三つの円」「余白」で象徴する。歌詞の解釈を勝手に固定しない。
- 色：深い紺 `#10171e`、グレー `#36424b`、温かな紙色 `#f5f4ef`、控えめな真鍮色 `#af9271`。
- 書体：Zen Kaku Gothic New を優先。その他はOS標準代替。大見出しは日本語の改行位置と可読性を優先。
- ファーストビュー：作者名、1st Single、タイトル、2026-11-22予定、主CTA「収録曲を見る」。リリース後は「聴く」に差し替え。
- セクション：収録曲 01《あなたと》（新録）、02《これから》（新録）、03《これからも》（新曲）／作品紹介／正式ジャケット／配信先リンク／クレジット／制作背景／MV（公開時のみ）。
- 発売前は未確認音源のプレイヤーも、架空のSpotify等のリンクも作らない。発売後は実リンクのみ表示。
- 配信と有料購入の導線を分離：作品体験を優先し、購入版は控えめなリンクで案内。
- MVが未公開なら告知も日時の確定前に表示しない。歌詞タイムシンク・歌詞配信の権利と各配信サービスの仕様を後日確認。
- SNS向けOG画像、縦長・横長のアート、表示文の短縮を正式素材に合わせて制作。

### C 共通データモデル案（秘密や正本実体は含まない）
```
work_id, title, kind, release_date, public_status,
master_verified_at, credits_verified_at, lyrics_verified_at,
```

- 未確認と公開可を別状態にする。データが空なら当該リンクを表示しない。

## 公開可のゲート
- **販売商品**：サービス利用の承認/許可、権利帰属、正式原本、品質校正、決済先確認、架空の他人による購入〜納品検証、返金・改訂・サポート方針が満たされたもののみ。
- **配信サイト**：実際に音源が配信事業者に受理され、配信日・クレジット・配信先・正式ジャケット・音源・歌詞が整合していること。発売前ページは本人が承認した範囲だけ。
- **公開前**：Mac/iPhone幅、404、SNSカード、キーボード操作、音源読み込み遅延、スクリーンリーダー、リンク切れ、キャッシュ、アクセシビリティを確認。
