# 《これからも》作品解説と縦読み｜v4編集案
更新：2026-11-08
対象：配信特設サイト PR #57。**未承認・非公開案**。元のv3は保存。
## 編集方針
- 作詞者の現在歌詞の意味を断定しない。結婚は解説の主語・主題にせず、成立背景にある小さな仕掛けとしてだけ扱う。
- 公開時の「作品紹介」と「制作ノート」を分け、冒頭の実体験、忘却、救われたこと、歌を届けたいという流れにする。
- 「雨」「目印」「おはよう」「僕たち」などの歌詞の記号を逐語的に答え合わせしない。
- 8行のうち**8文字目**を縦に読むと「けっこんしました」となる。文頭に不自然な促音「っ」、撥音「ん」を置かない。
- 前置きはすべて7文字（全角日本語）。文字ごとのスペース、色、太字、下線など強調をせず、読みたい人にだけ発見されるようにする。
- DOM上の文字は普通の日本語としてそのまま連続して読み上げられること。携帯幅の折返しでも8列目の最初の文字位置をそろえる。
- **縦読みの公開日は本人が個人的な公表を承認した後**。音楽公開と自動的に連動させない。
- 文案にある「歌にしておきたかった」「もう一度出会えたら」等の言葉が作者の想いと一致するかは未確認。本人確認後に全文を校正する。
## 設置・動線
- 公開用の《これからも》簡潔紹介文から「制作ノート」の折りたたみに進める。現試作は可視にして組版を確認する。
- 公式トップには縦読みの存在を告知しない。特設サイトの3曲目に興味を持った人が読む。
- note記事や販売サイトにはこの仕掛けを自動転載しない。
## 独立した後工程
1. 本人の原文として承認するか判定。とくに「思いがけず」「何度も」「届けたかった」等のニュアンスを確認。
2. 縦8文字の一致、自動・手動改行、375px/390px/768px/1440pxでの表示を検査。
3. アクセシビリティ検査：各行を文章として順序正しく読み上げること。
4. 公開可否を販売業務・配信業務と独立して管理。許諾が取れない場合は非掲載。
