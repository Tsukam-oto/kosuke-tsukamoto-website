## 3. 時刻・状態の設計（日本時間）
- **11月21日23:59まで**：今の「11.22 発表まで」カウントダウン。曲名もソースコードに先に埋め込まない方針なら、サイト更新は公開時に限定。
- **11月22日00:00〜11月29日23:59（提案）**：初回訪問時のみ1回ポップアップ。クローズ後も、カウントダウン跡が「1st Single発表／作品を見る」常設導線に変わる。
- **11月30日以降（提案）**：新しい訪問者もポップアップの自動表示はしない。作品への導線は残す。
- 同一ブラウザでは `localStorage` のリリースID単位のフラグを使って再表示を避ける。閲覧者がボタンから再表示することは可能。
- JS無効時は、ポップアップではなく通常のトップ内告知リンクから入れる。
- 11/22以降、現在の `section.hidden = days < 0` によって告知が消える問題を修正する。
- ポップアップでの自動再生・ポップアップ再表示の連続発生をしない。

- タイトルが31文字程度でもスマホで切れない。余白と改行に違和感がない。
- 閉じる、Esc、外側クリックで閉じられる。閉じた後に元のページが操作できる。
- 背景スクロール抑制とフォーカス管理は、本番実装時にアクセシビリティ要件として確認。
- 1ブラウザにつき自動表示は一度だけ。再訪問で繰り返し出ない。
- 特設ページのリンク先が404にならないこと（11/22公開と同時にセット）。
- 11/22発表と実際の配信開始日を混同させない。
- 開始日以降もTOPICS・ホームバナーから継続的に探せる。
- 過去の歌詞・LYRIC BOX・音源・教育資料・問い合わせフォームなど既存資産に差分を生じさせない。
- 本番デプロイはデザイン・ジャケット・コピーの承認後のみ。
