- サイト来訪直後に「何の作品か」、1操作で「どんな音楽か」、次に「3曲の背景」、最後に「制作ノート」。
- イントロを11/22に、サビは数日後という2段階公開。長さ・切り出しは完成音源を確認してから決める。
- 告知と配信の違いを明示：「配信決定」は可。ただし `11/22配信開始` は不可。 `配信開始日は確定次第発表` を同画面に表示。
