# 《これからも》制作ノート｜精度改善 v5（2026-11-08）

## 狙い
縦読み「けっこんしました」を維持しつつ、前案の「大げさな言葉にしないまま」「しまい込まず」などアクロスティック優先に見える箇所を除去。歌詞から確認できる事実だけに基づく暫定的な**制作ノート**として整えた。結婚を曲の唯一の主題として扱わない。

## v5 原稿（非公開・作者未承認）
あのとき思いがけず、自分のこれからを喜んでくれる人がいた。

肩を叩く手があって、照れくさくて、少し誇らしかった。

忘れてしまったことも、ふとしたときに思い出す。

それでもたくさんの人に、救われてきた。

人といることがしんどい日もある。

答えも出ないまま、ひとりで歌詞を書いている。

誰かのことを少し考えながら、続きを書いた。

いつか思い出したとき、この歌もそこにあったらいい。

## 仕組みの検査

- 1〜7文字目の長さ: `7,7,7,7,7,7,7,7`。
- CSSで7em/1emの先頭列を固定。日本語文字単位の位置は実機で再確認する。

- 本文そのものが作者にとって自然であることを優先。本人確認なく「本心」と断定しない。
- iPhone等で、1行が二段に折れた場合にも8文字目の縦位置が崩れないか要確認。
- 結婚報告と読める内容であるため、正式に公表可能な段階まで下書きPRで保留。

## 意味と留意点
1. 1〜2行：未来を喜んだ人／肩を叩かれた具体的な瞬間。旧版の「出来事がきっかけで」は説明でなく場面を描く。
2. 3行：忘れることと、再び思い出すこと。歌詞の「目印」の答え合わせはしない。
3. 4〜5行：人に救われてきた事実と、その関係がしんどくなる日もある矛盾を並べる。人とのつながりを美化しない。
4. 6〜7行：幸せの結論が出ないまま、一人で歌詞を書き、誰かへ思考が向かう。一人でいる／独りではないを説明しすぎない。
5. 8行：歌を記憶の中に置けたら、という控えめな願い。永続や救済を保証しない。

## 編集上、本人に最終確認が必要な点
- 「思いがけず」の意外さは実際の体験に合うか。
- 「しんどい」は本人の「煩わしい」に近い温度感か。
- 末尾の「この歌もそこにあったらいい」は、実際に伝えたい願いとして正確か。
- 最終的な歌詞・クレジットは最新の正本と照合する。歌詞には手を入れていない。
