## 動画マスター
- 1080×1920 / 9:16 / H.264 MP4 / 30fps想定。Final Cut Proで横／縦安全域を確認。
- 歌詞映像は必ず正式歌詞の文字と発音を照合。歌詞の解釈を説明しすぎず、先行音源は楽曲を主役にする。
- ジャケット正式版があれば使用。MV素材がなければピアノ・風景・文字だけでも成立させる。
- イントロ：開始0〜3秒以内に作者名と作品タイトルを認識できること。最後は「2026.11.22 1st Single 発表」「配信日は後日発表」。
- サビ：聴かせたい歌詞のフレーズが1〜2行入る位置を選ぶ。末尾までサビを消費して説明しすぎない。
- 同じ動画を書き出し、YouTube ShortsとTikTokへ個別アップロード。他社ウォーターマークを含む転載は避ける。
