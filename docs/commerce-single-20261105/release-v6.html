01あなたと令和6年度・新録＋

卒業を前にした生徒たちの言葉から生まれた合唱曲。楽しかったことだけでなく、悔しかったことや、周囲の人に支えられてきたことも振り返りながら、感謝と新しい一歩への気持ちを歌っています。

原曲：令和6年度 卒業記念創作合唱
作詞：令和6年度3学年一同・束元康介 ／ 作曲：束元康介

02これから令和7年度・新録＋

いつもと変わらない景色が、もうすぐ最後になる。卒業を迎える生徒たちの言葉から生まれた合唱曲です。仲間と積み重ねた時間、すれ違い、支えてくれた人、そして後輩に託す思いが歌詞に残されています。

原曲：令和7年度 卒業記念創作合唱
作詞：令和7年度3学年一同・束元康介 ／ 作曲：束元康介

03これからも2026年・新曲＋

自分のこれからを喜んでくれる人がいたことから、人とのつながりや幸せについて考え始めた曲。忘れることも、変わっていくことも受け入れながら、音楽と人に救われてきた自分の現在を歌っています。

作詞・作曲：束元康介

TRACK 03 / NOTE

《これからも》について

人と出会い、離れ、忘れ、思い出す。その繰り返しの中で、自分が受け取ってきたものと、今日の先にある時間を見つめながら書いた曲です。

制作ノート

あのとき思いがけず、自分のこれからを喜んでくれる人がいた。

肩を叩く手があって、照れくさくて、少し誇らしかった。

忘れてしまったことも、ふとしたときに思い出す。

それでもたくさんの人に、救われてきた。

人といることがしんどい日もある。

答えも出ないまま、ひとりで歌詞を書いている。

誰かのことを少し考えながら、続きを書いた。

いつか思い出したとき、この歌もそこにあったらいい。
