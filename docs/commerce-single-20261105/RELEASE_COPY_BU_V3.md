## この作品について
私が音楽をつくってきたのは、まず身近な人たちに聴いてほしかったからです。だから、創作の中心にはいつも学校がありました。

《あなたと》と《これから》は、それぞれの卒業生と一緒につくった、私にとって大切な2曲です。今回、自分の歌とピアノで新しく録音しました。レコーディングもすごく楽しくて、最初はこの2曲だけを配信しようと思っていました。

学校には卒業があり、教員には異動があります。毎日顔を合わせていた人とも、ずっと同じ場所にいられるわけではありません。学校での創作はこれからも続けていきますが、離れた場所にいる人にも音楽を届けられるようにしたい。それが、配信を始めようと思った理由です。

でも、2曲だけで終わりたくはありませんでした。今の自分が考えていること、そしてこれからも音楽を続けていく気持ちを、曲として残しておきたいと思いました。

そうして加えた新曲が、《これからも》です。

## 《これからも》制作ノート
自分のこれからを話したとき、それを喜んでくれる人がいました。そこから、これまで関わってきた人たちや、今の自分のことを考え始めました。

私が曲を書き続けている間に、元気でいてほしい人が増えました。  
そんなふうに思っている自分の今を、残しておきたくなりました。  
歌を残しておくことは、いつか思い出すためでもあります。  
これまでたくさんの人に、支えてもらいました。  
いつかまた話がしたい人も、今ここにいる人もいます。  
幸せのことは、まだよく分かりません。  
いつも通り暮らして、また「おはよう」と言い合えたらと思います。  
音楽を続けてきた。これからも、変わっていく風景の中で曲を書いていきます。
