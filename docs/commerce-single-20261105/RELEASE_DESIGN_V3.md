# 1st Single 配信特設サイト｜実装指示 v3
更新：2026-11-06
対象：束元康介 1st Single『あなたと、これから、これからも』
現在：新規デザイン試作であり、本番ページではない。

## 設計判断
- 既存の試作v2は、タイトルをジャケット風正方形の中にも反復、745pxの巨大ヒーロー、聴く導線が曖昧、編集中の注意書きが本文へ混在。
- v3は白・黒・淡いグレーに統一し、タイトル、正式ジャケット、曲、配信先を優先。正式ジャケットにあわせてアクセント色を決定するまで特有の青色は使わない。
- 誇張する宣伝文句や卒業を美化する文章は置かない。「本人の歌とピアノで」「今度は」は表面コピーから除外。
- 初見の人が3曲を知り、卒業生は当時の年度に気付ける形で情報を二層にする。
- noteは文章・制作の記録、販売サイトは楽譜やGAS販売。特設ページでは配信を主目的にし、公開URLの実確認後にフッター程度で接続する。

## 画面順と対応コンポーネント
1. ヘッダー：束元康介／公式サイトに戻る。メニューや販売リンクは載せない。
2. HERO：1st Single、日付、3行の作品名、作家名、短い事実紹介、【発売前：収録曲を見る／発売後：確認済み配信先で聴く】。正式ジャケットは空欄を維持し架空画像を使わない。
3. TRACKLIST：01 あなたと（令和6年度卒業記念創作合唱、新録）、02 これから（令和7年度同、新録）、03 これからも（新曲）。タイトルとタグは常時可視。各曲詳細はネイティブdetails。
4. ABOUT：確認済みの制作経緯だけ、短い2段落。本人提供の写真・制作ノートは完成版で選定する。
5. RELEASE：ストリーミングはディストリビューターの公開URL実確認後だけリンク化。架空リンク・無反応ボタンを置かない。
6. フッター：公式サイトへのリンク。note/販売先は別トークで完成後、URLと目的が一致する場合に追加。

## 開発用注記と本番本文を分離
- 「正本照合後に掲載」や「これから加える内容」などは本番公開版にそのまま残さず、実データを載せるかセクションを削除する。
- 販売準備中の価格や利用許諾は配信サイトに書かない。
- 配信サービスはリンクの存在だけでなく実際の公開先を確認する。
- 自動的に配信日に「配信中」へ切り替えてはいけない（流通の遅延があり得る）。
- 《あなたと》旧Web掲載データの取り違え指摘あり。新音源・ジャケット・歌詞・クレジットは本人による正本照合前に流用不可。
- 学校や卒業生の未許諾データを掲載せず、購入の勧誘を学校活動へ持ち込まない。

## Codex 実装単位
1. PR #57 内の比較試作として v2を保護し、今回の v3.html を掲載。公開サイトにはまだマージしない。
2. 提供された正式ジャケットを表示し、代替テキスト・画像最適化・スマホのLCPを検証する。
3. 正式マスター音源、3曲の曲名表記とトラック順、歌詞、作詞作曲・ボーカル・ピアノ・録音関係クレジットを作者と照合する。
4. ファーストビューから1操作で正式な再生・配信画面に進めること、375/390/768/1440pxで横スクロールしないこと、detailsのキーボード操作とフォーカス、OG画像とSNS共有プレビューを確認する。
5. 配信前状態→公開済み状態の切替を設定で管理し、デプロイ後に本人が確認した内容だけ公開する。
6. 公式サイトトップには既存の4入口、LYRIC BOX、THANKSを保ったまま、「1st Single」小型カードを一か所だけ追加。特設ページへのリンク、楽曲情報とプレビューの一致を検証する。

## 受け入れ条件
- 卒業生に向けた感動のコピーなしで、各作品の年度が一目で分かる。
- 3曲を知らない人にも曲名・配信先が分かる。
- 作品名のジャケット風重複なし。
- fakeの再生ボタン／購入ボタンなし。
- 実際のジャケットがない段階の仮画面を本番に出さない。
- noteと販売サイトの独立性を保つ。
