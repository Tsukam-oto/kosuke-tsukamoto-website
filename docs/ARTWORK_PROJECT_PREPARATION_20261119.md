# ARTWORK PROJECT｜《あなたと》《これから》シングルカット用ジャケット公募

**作成: 2026年11月19日｜内部準備資料・未公開・募集未開始**

## 確定している制作方針
| リリース | アートワーク |
| --- | --- |
| 1st Single『あなたと、これから、これからも』 | 奥様が制作する正式ジャケット。公募しない |
| 《これからも》単独版 | 1st Singleと同一画像を希望。ただしNARASUで再利用可能か要確認 |
| 《あなたと》単独版 | **ジャケットを一般公募** |
| 《これから》単独版 | **ジャケットを一般公募** |

《あなたと》《これから》のシングルカット用公募は、3曲入り作品の**配信開始後**に始める別企画。
11月22日（配信決定発表日）の公式トップポップアップ／特設ページ冒頭では告知を行わず、作品と奥様制作ジャケットを主役にする。

## 予定する公開導線（要項確定・募集開始後のみ）
- 1st Singleの特設ページ `/releases/2026-11-22/` の **TRACKSの後、配信情報の前** に控えめな「ARTWORK PROJECT」案内を表示する。
- 公募専用ページ `/releases/artwork-project/` をそのとき公開する。募集要項、応募先、締切、選考基準、Q&A、採用結果（本人了承後）をここに集約。
- 公式サイト `/works/` や `/releases/` の告知は「募集開始後」にのみ表示。
- 応募受付は**教員・学校の提出システムや生徒個人情報と分離**。アクセス権を絞り、不要な個人情報は収集しない。
- ページ公開、募集開始、応募者への連絡は、本人の内容確認と明示的な公開指示があるまで行わない。

## 募集要項で決めなければならない項目
1. 募集対象の2作品：《あなたと》《これから》を別部門にするか、両方同時応募可にするか
2. 応募資格・未成年者の保護者同意の扱い
3. 応募開始日、締切日、結果発表日、審査体制、応募作品数
4. 応募作品の規格：正方形、入稿解像度、ファイル形式、RGB等（NARASUの最新仕様を正式確認）
5. オリジナル作品条件、第三者の著作権・肖像権、生成AI使用作品の扱い
6. 採用者の対価・謝礼の有無、権利の帰属、商用配信・宣伝・SNS・サイト使用許諾、加工やトリミング許諾、使用地域と期間
7. アーティスト名・曲名の文字を作者が追加するか、応募作品に含めるか
8. 採用者のクレジット表記方法、匿名・ペンネームの扱い
9. 応募先（フォーム・メール等）・確認返信・問い合わせ先・ファイル保管・個人情報保護・保管期間
10. 不採用作品の扱い、応募取り下げ、募集中止時の扱い
