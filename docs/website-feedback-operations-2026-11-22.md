# 公式サイト｜投稿の受付・確認・掲載ルール（2026-11-22）

## 送信元の区別
すべて同じ Formspree フォーム `xbgjraga` に届きます。件名・project・category で識別してください。

| 送信元 | project | 内容 | 公開について |
| --- | --- | --- | --- |
| 1st EP 感想 | `first-ep-2026-11-22` | `voice`、任意の `name`、`publication` | `掲載しない` が初期値 |
| VOICE BOX | `voice-box` | `voice`、`theme`、`publication` | `掲載しない` が初期値 |

| 一般お問い合わせ | `website-contact` | `name`、`email`、`category`、`message` | 一般公開しない |

## 受信の最終確認（公開後に所有者が実施）
1. 公開サイトのEPページから、個人情報を含まない短い確認文を1通送信し、そのページ内に「メッセージを受け付けました」が表示されることを確認する
2. Formspreeダッシュボード／転送先の受信メールを確認し、`project=first-ep-2026-11-22`、`publication=掲載しない`、本文が届いているか確認する
3. 続けてジャケット制作希望フォームと一般お問い合わせ・VOICE BOXも、必要ならテスト用の連絡先を使って1回ずつ確認する（実際の応募者宛てに連絡しない）
4. 送信成功が不明な場合はむやみに再送しない。Formspree側の受信を先に確認する
5. テストメッセージは管理画面で識別して、不要になったら削除する

**GitHubのブラウザQAは送信先を模擬しているため、Formspreeアカウント側の実受信を証明しません。**

## 問い合わせ整理（公開しない管理用）
- `未確認` → `確認済` → `返信中` → `完了` の4段階で対応状況を管理する
- Formspree管理画面または非公開の管理台帳で、分類／受信日時／匿名掲載可否／担当／対応状況を追う
- 感想の掲載は明示的に `匿名で掲載してよい` を選んだ投稿だけ。掲載前に内容を読み、個人情報と第三者特定情報を削除する
- ジャケット応募と一般問い合わせは掲載素材に転用しない
- メールアドレスや本文を公開GitHub、静的JSON、HTML、閲覧可能なCSVに保存しない
- 送信内容を端末側に永続保存しない。フォームの送信成功後は送信ボタンを無効化して二重投稿を防ぐ

## フォーム仕様（運用上の注意）
- JavaScript対応ブラウザでは、FormDataをFormspreeへPOSTし、成功／エラーをページ内に表示する
- JavaScript無効時には通常のHTMLフォームのPOSTへフォールバックする
- HTTPエラーでは入力を維持して再送できる。ネットワーク切断時には受信済みの可能性があるため再送を促さない
- 個人情報を含む投稿内容をブラウザのURL、解析イベント、ログに記録しない

## 配信告知を更新するとき
- 2026-11-22は「1st EP配信決定発表日」。配信開始日ではない
- トップページのSNS共有用OGP画像と説明文は、今後の作品の告知期間に合わせて更新する
- メディアURLや配信開始日は確定した情報だけを掲載し、想定で追加しない
