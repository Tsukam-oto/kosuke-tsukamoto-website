# ARTWORK PROJECT｜応募データの取扱い・公開前監査

作成：2026-11-19。対象PR #68。**応募者情報をGitHubのソースや公開Issue、READMEに記録しないこと。**
このファイルは運営手順であり、Formspree側の設定確認や応募データの受領・削除が自動で完了したことを意味しません。

## 実際のデータの流れ
1. 応募者が `/releases/artwork-project/` に名前または活動名、メールアドレス、曲、作品画像のHTTPS共有URL、任意コメントを入力
2. 応募者が **応募条件／個人情報の取扱い** それぞれに同意
3. `https://formspree.io/f/xbgjraga` にHTTPS POST（公式サイトの既存 `/contact/` と同じ受付フォーム）。現時点では **公募専用Formspree IDではない**
4. Formspreeで申込情報を処理・保存し、設定された通知先に案内する場合がある（通知先・自動返信・ワークフローは未確認）
5. 運営者がリンク先の画像を閲覧。**画像そのものはフォームに添付されない**。Google Drive等の各ストレージサービスが画像を保持
6. 作品の審査・候補者への連絡・採用条件の個別合意、不要な応募情報の削除

## 公開前に必須
- [ ] Formspreeにログインし `xbgjraga` が本人のアカウント内のフォームか確認
- [ ] 送信先メールアドレス、通知設定、スパムフォルダ、ドメイン制限、容量とプランを確認
- [ ] **公開前に公募専用Formspreeフォームを新設し、専用のForm IDへ差し替えること（推奨ではなく公開ゲート）**。通常のお問い合わせと応募データを同一一覧に混ぜず、専用受信先・通知・保存期間を管理する。Formspree公式仕様では無料プランでもフォーム数は無制限だが、無料プランは月50送信、管理画面の直近30日分のみ表示（古いデータは自動削除されない）。
- [ ] 応募者の名前、メール、作品URLを使う実送信テストを、本人所有の架空・検証用データ1件で行う。実応募者情報をテストに使わない
- [ ] ダッシュボードの受信記録と通知メールを両方確認（送信後に成功画面へ移動するだけでは、通知先・運営者の受信を保証しない）
- [ ] 実受信テスト後、テストレコードを削除
- [ ] 自動返信があると想定しない。必要であれば Formspree アカウントのプランとAuto Response機能を確認
- [ ] 公募規約の応募期間・選考時期・謝礼／無償・採用作品の利用条件を本人が承認
- [ ] 公募ページと応募先が2026-11-22まで一般公開されないようデプロイ日を管理（静的URLは main に反映すると誰でも直接開ける）

## 運用中
- FormspreeのForm IDや送信先メールを、非公開の管理メモで記録して管理。Form IDの公開自体は通常のHTMLフォームに必須だが**APIキーなどの認証情報は絶対にGitHubへ置かない**
- 「応募曲」「作品URL」「連絡用メール」「受付日時」「状態（未確認／リンク確認待ち／審査中／候補者連絡／不採用／採用／削除済み）」を管理
- ただし**実応募者の氏名・メール・URLを公開リポジトリ、Classroom、学校用Google Drive、共有の学習DBに保存しない**
- 受信通知の配信失敗に備え、Formspreeのダッシュボード自体を定期確認する
- Formspree無料プランでは管理画面で閲覧できるのが直近30日で、古い応募は自動消去されない。必要なら権限を絞った管理台帳に適切に転記し、終了後に削除
- URLは応募者の希望する共有範囲で運用。「リンクを知っている全員」は**公開されたファイルではなくてもURL保持者が閲覧できる状態**なので、募集ページで説明する
- リンクにアクセスする際はドメインと内容を確認し、不審なダウンロードやアプリ実行をしない
- 画像やテキストをAIツールへ無断転送せず、審査に必要な範囲の者だけがアクセスする
- 作品の権利・使用条件の合意までは、応募画像を宣伝・配信・SNSへ掲載しない
- 取り下げやデータ削除依頼に対応し、対象のFormspree受付記録、通知メール、運営者側に保存したコピーを必要に応じて削除する。応募者側のGoogle Driveなどは運営者が削除できない
- 公募終了後、不要になった応募情報を削除する運用の実行を確認する
