# ARTWORK PROJECT｜初回メッセージ受付のデータ管理

更新：2026-11-19 / PR #68。画像作品を集めるのではなく、**制作希望の連絡のみを受け付ける**方式。

## 最初に取得するデータ
- お名前・活動名／メールアドレス／希望曲／メッセージ
- 「中学校を卒業済みであり、18歳未満なら保護者同意を得ている」確認
- Formspree経由で送信・保存することへの確認
- **作品画像・画像URL・学校名・年齢・住所・本人確認書類は取得しない**

## データの流れ
1. 一般の希望者が `/releases/artwork-project/` のフォームから初回メッセージを送る。
2. 外部サービスFormspree（現行 `https://formspree.io/f/xbgjraga`）にPOSTし、サービス側に保存され、設定次第で主催者へ通知される。
3. 受付後に本人がメールで個別に制作条件を相談。応募者の連絡先をサイトやSNSに公開しない。
4. 必要に応じ、**制作条件と謝礼の内容を事前に合意した方とだけ別途作品データをやり取りする**。配信ジャケットや宣伝で使う前に、著作権の使用許諾、掲載媒体・期間・加工・クレジットなどを個別に書面で確定する。無断利用しない。
5. 相談終了後など、不要になった個人情報はFormspreeと通知メールを含めて削除する。

## 受付前チェック
- [ ] Formspreeログインで実際の受信先・アカウント・通知メールを確認。
- [ ] 公募専用Formspreeフォームが利用できれば分離することを推奨。**初回はメッセージのみで、専用フォームが未作成の場合も専用件名で振り分けられるが、他の相談と同じ管理画面に混在することを理解する。**
- [ ] 本人所有のダミーデータで一通だけ実送信し、受信履歴と通知を確かめる。実応募者をテストに使わない。
- [ ] 送信の二重受付や迷惑メール対策、Formspreeの契約枠を確認。
- [ ] 依頼の辞退・個人情報削除の問い合わせに対応できる連絡先を確認。
- [ ] 18歳未満の採用候補者は、保護者の同意を別途確認する。初回チェックのみで最終の利用許諾契約を成立したと見なさない。
- [ ] 11月22日まで不用意にmainへ反映しない（公開静的URLは直接アクセス可能）。

## 運用ルール
- 管理する状態は「新着／返信済み／相談中／制作調整中／辞退／削除済み」など。個人情報を公開GitHub・学校のシステム・共有教材DBに記載しない。
- 公募が始まったらFormspreeのダッシュボードを継続確認する。通知メールだけに頼らない。
- 作品ファイルが送られてきたときは、必要な利用権の合意まで宣伝や配信に使用しない。
- メール返信や作品公開は本人確認の上で行う。自動返信や実応募者への送信はまだ設定していない。
