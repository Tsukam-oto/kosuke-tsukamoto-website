## 1. 役割と商品構成

- **公式サイト**：作品を知る・試聴する・GASの架空データ体験版を使う・各購入先に進むための正本。公開サイトの購入ページは、販売承認までは購入不可。
- **BOOTH**：私的制作の楽譜PDFと独立したGAS製品の一般向けデジタル販売。購入者はダウンロード、BOOTHで決済。
- **音源配信**：Apple Musicはストリーミング、iTunes Storeはダウンロード購入。配信代行業者（DistroKid/narasu）は未決定。BOOTHへの同一音源重複出品を前提にしない。
- **公費購入**：BOOTHの即時購入を学校の後払い・事前決裁の代替とみなさない。必要に応じて書類を確認したうえで個別に見積・納品・請求。学校側がBOOTH決済を認めるなら一般購入も選択肢。
- **特別利用許諾**：音源の広告・映像への組込み、団体外複製、編曲などは権利確認後の個別相談。基本的な同一団体内の利用許諾を商品価格と二重請求しない。

## 2. ショップ名・デザイン（候補／本人未承認）

候補：**束元康介｜楽譜と音楽教育ツール**

ショップ紹介文の下書き：
> 作曲家・音楽教育者として制作したオリジナル楽譜と、音楽活動の現場で役立つデジタルツールを紹介するショップです。作品・ツールの内容、導入方法、利用条件は各商品ページに記載します。正式な販売は準備中です。

ショップ名は表示名として後から変更できるが、**サブドメインはショップを一度でも公開すると変更不可**。名称やサブドメインを決めるまでは公開しない。公式サイトの作品世界を優先し、装飾のためだけに別ブランドを乱立させない。

希望するデザイン：
- Zen Kaku Gothic Newに近い読みやすい文字組。ただしBOOTHのUI/書体には制約がある。
- ヘッダー/アイコンは公式サイトのブランド資産と整合。学校標章・学校の写真・生徒の画像・学校向け内部資料を流用しない。
- 楽譜商品：白地に作品タイトル、編成、難度・演奏時間（実測・原譜確認後のみ）、同梱内容。
- GAS商品：機能の図解、必要なGoogle環境、導入時間（実測後）、サンプル画面と権限の説明。
- 紛らわしい「認定」「学校公式」「東京都推奨」等は表示しない。

## 3. ショップ開設の順番（本人が行うアカウント操作）

- [ ] 管理職・所管部署へ営利活動の準備／販売の許可・申請要否を照会。販売開始前の必須手続を記録。
- [ ] 個人のpixiv/BOOTHアカウントを使用。学校ドメイン・学校契約アカウントは使用しない。既存の本人アカウントがあれば重複作成を避ける。
- [ ] ショップ名とサブドメインの綴りを決定。**初回公開前**に確認する。
- [ ] ショップを非公開で設定。BOOTHの「ショップの公開設定」を確認する。
- [ ] ショップ説明、アイコン・ヘッダー、問い合わせ窓口を設定する。本人の住所・振込口座などを公開リポジトリに記載しない。
- [ ] 特商法の表示要件（販売業者該当性、表示・省略可否、連絡先など）を事前確認。BOOTHだから自動的に表示免除とは決めない。
- [ ] 商品は**非公開の下書き**で登録。販売価格・ダウンロードファイルの実体・利用許諾を承認していないなら公開保存を選ばない。
- [ ] 購入者向けFAQ・更新・返金対応方針を、現行BOOTH仕様に適合させてから商品公開。本人の明示承認を経る。
- [ ] 売上管理／入金・会計記録を私的環境で整理。本人の勤務校・生徒データとは完全に分離。

**注意**：ショップの「非公開」と商品自体の「下書き」を併用。ショップ非公開のまま商品を「公開で保存」しても、BOOTH上の最初の商品公開日時はその操作時点となり得る。公開日表示の整合まで考慮する。
