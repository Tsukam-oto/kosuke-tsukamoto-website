# 販売事業｜兼業・服務の事前照会キット（内部作業用・未送信）

更新：2026-11-05　状態：照会前／許可・承認未取得／販売不可

この文書は検討事項と質問文のひな形です。所管機関からの回答、許可、承認、権利帰属の確認を代替しません。人物・住所・勤務校・申請書の実物や回答の個人情報を、公開リポジトリに記録しません。

## 1. 相談経路と法的な切り分け

1. 学校管理職に「自作の楽譜・ソフトウェア・音源の有償提供を検討している。職務資料とは分離し、販売前に正式な手続を確認したい」と相談する。
2. 管理職経由で、区教育委員会の教職員服務・人事担当部署、必要に応じて東京都側の所管部署を確認する。担当課・許可権者は推測で確定しない。
3. 自分の任用区分を確認したうえで、教育公務員特例法第17条の「教育に関する他の事業等」への該当と、地方公務員法第38条の営利企業等従事の制限を、販売方式ごとに照会する。県費負担教職員の場合の読替えを踏まえるが、個別の承認・許可手続は担当部署に確認する。
4. 口頭で回答された場合も、根拠規程・所定様式・適用される販売形態を記録し、可能であれば文書で回答を得る。曖昧な場合は販売しない。

参考（一次情報）：

ある方式が認められても、他方式まで自動的に認められるとは限らない。

## 3. 初回相談に添える事実説明（本人による確認が必要）

- 作業場所と時間：勤務外・私的な設備と個人契約のアカウントを利用する方針。
- 商品：GAS審査集計ライト、独立した自作楽譜、正式録音、限定的な利用許諾。
- 販売対象：勤務先の生徒・保護者への勧誘を行わない。勤務先での予算執行を本人販売の前提にしない。
- ソース・素材：学校の名簿、児童生徒情報、学校アカウント、学校のライセンスを私的販売に持ち込まない。
- 著作者・権利者：学校行事に関連する作品と職務上作成したプログラムについては別に権利帰属を確認し、未確認の素材は販売しない。
- 業務見込み：月間の制作・販売・顧客対応時間、予定価格、収入の受け取り方を追加して説明する。実態が未定なら「未定」と明記する。

「私的制作のつもり」は権利帰属や服務許可の証明にはならない。根拠記録を別途用意する。

## 4. 管理職・所管部署向け照会文（送信前に本人が確定）

件名案：私的制作物の出版・販売に関する兼業等の事前照会

区立学校の教員として勤務しています。勤務上の義務や利益相反を遵守するため、私的に制作した作品・ソフトウェア等について、販売の開始前に所管規程と必要な許可・承認・届出を確認したいと考えております。

検討している活動は、(1) 自作曲の出版社・配信会社経由の印税等の受領、(2) 自作楽譜のデジタル自己販売、(3) 教育・審査用の独立したGASツールの販売・購入者サポート、(4) 学校への見積・納品・請求書による販売、(5) 録音音源の配信収益、(6) 個別の著作物利用許諾です。

各活動について、教育公務員特例法第17条または地方公務員法第38条等との関係、事前許可・承認・届出の要否、許可権者、提出先、申請様式、審査に必要な資料、活動範囲や時間・金額の条件をご教示いただけますでしょうか。

あわせて、学校行事のために制作した楽曲、学校の業務を契機に開発したプログラムの個人名義での販売可能性について、権利確認の相談先と確認資料をご教示ください。勤務先での教材選定・予算執行に本人が関与する場合の利益相反も避けたいと考えております。

なお、現段階で有償販売・受注・金銭の受領は開始しておりません。必要手続が確認・完了するまで販売いたしません。

以上、よろしくお願いいたします。

## 6. 禁止すべき先走り

- 許可不要と自己判断して販売ページを決済可能にしない。
- 学校・児童生徒の資料を販売商品の試験データに流用しない。
- 学校の予算や同僚への勧誘を初回売上の見込みに含めない。
- 無許可で販売してから事後申請する手順にしない。
- 本人が権利者だと確認できない素材に利用許諾を出さない。
