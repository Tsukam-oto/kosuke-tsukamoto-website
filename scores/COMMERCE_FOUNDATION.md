# 4分野共通｜販売基盤の最小設計（下書き）

更新：2026-11-05　未実装／販売未開始。設計資料であり、外部への正式な販売条件ではない。

## 1. 目的と対象

GAS、楽譜、音源、特殊利用許諾を4つの別事業にせず、商品台帳・権利台帳・許諾条件・受注記録・帳票を共通化する。最初はGASとファンファーレだけが対象。音源・特別許諾は将来同じ台帳に追加する。公開サイトは紹介と外部決済への案内に限定し、顧客記録と請求書作成を公開Webには置かない。

**最初から作らないもの**：独自クレジットカード決済、月額課金、購入者アカウント、購入番号の自動認証、全自動の学校公費決済、永続サポート契約。

## 2. 商品台帳（機密情報・個人情報を含まない）

| フィールド | 用途 | 例（まだ発売しない） |
|---|---|---|
| product_id | 永続的な識別子 | GAS-CHORAL-001 / SCORE-FAN-004 |
| kind | 商品系列 | GAS / SCORE / AUDIO / SPECIAL_LICENSE |
| title / edition | 正式商品名・版 | 審査集計ライト / 0.1候補 |
| rights_owner_status | 許諾できる権利の根拠 | 未確認 / 確認済 |
| employment_clearance_status | 服務判断と根拠資料の有無 | 未照会 / 回答済 / 手続済 |
| package_manifest | 配布物の一覧・版・チェックサム | GASコード・導入手引・利用許諾書 |
| license_code | 標準許諾文書の版 | GAS-SCHOOL-1 / SCORE-GROUP-1 |
| tax_inclusive_price | 税込予定価格 | GAS未定 / FAN 1000円案 |
| channel | 外部販売と公費相談 | 外部ショップ / 学校個別相談 |
| support_policy_version | サポート条件の版 | 未確定 |
| release_state | 公開の許可判定 | draft / blocked / approved / live / retired |

**禁則**：release_stateがapprovedにならない限り、注文フォーム・外部ショップ商品リンクを本番表示しない。approvedからliveへの変更には本人の別途明示承認を必要とする。

## 3. 利用許諾の原則（確定前の設計方針）

| 商品 | 基本商品に含めたい利用 | 基本商品に含めない利用 |
|---|---|---|
| GAS | 購入した1学校・1団体での利用、校内担当者による運用・設定変更・複製 | 他校への配布、再販、無期限の保守義務 |
| 楽譜 | 1団体内の演奏準備に必要な閲覧・印刷・継続利用（許諾できる場合） | 団体外共有、ネット公開、音源・映像等の権利まで一括付与 |
| 音源 | 配信契約に従う視聴・私的利用、別途購入商品の明記された用途 | CM・動画BGM・第三者への素材再配布 |
| 特別許諾 | 作品・許諾者・目的・期間・地域・対価を特定した個別契約 | 口頭で用途無制限に許諾、他者の権利を代理で勝手に許諾 |

「演奏する権利を買う」と誤認させず、楽譜複製・使用許諾を明記する。著作権法の例外規定・管理事業者の委託範囲・大会規程は別途適用される。通常利用分を追加の『ライセンス料』として二重請求しない。

## 4. 受注〜納品〜入金の状態

### A. 一般購入（外部ショップ）
公開ページ閲覧 → 販売先に移動 → 外部ショップで決済 → ダウンロード提供 → 購入履歴・問合せ対応。
購入者のメール・購入番号等を外部から独自台帳に転記する場合は必要最小限にとどめ、保存目的・権限・削除を定める。クレジットカード情報は収集しない。

### B. 学校公費
事前相談 → 学校側の必要書類確認 → 見積書 → 校内の事前決裁 → 正式発注 → 版を固定して納品 → 納品書・請求書 → 支払い確認 → 完了。
「問い合わせ＝正式受注」ではない。学校がPDF・ライセンスを調達できるか、源泉徴収・振込条件・適格請求書の要件を個別確認する。取引先に必要な契約情報だけを安全な私的環境に保管。

### C. 特別許諾
用途の聴取 → 権利者・委託範囲の確認 → 条件書案 → 合意 → 必要な権利処理 → 許諾書発行・請求 → 記録。
権利者未確認の作品は見積確定・許諾書発行を行わない。

## 5. 私的な受注・会計記録の項目（公開リポジトリに実データを置かない）

- order_id、商品ID、版、販売チャネル、取引先区分、注文/納品/入金日、税込対価。
- 販売手数料、振込手数料、返金、実際の入金額、必要に応じた源泉徴収・消費税の処理区分。
- license_id、許諾相手、許諾範囲、許諾書の版、購入証明の保管先。
- 公費の見積番号、発注書・納品書・請求書の対応関係。
- サポート履歴、重大不具合、修正版、購入者への通知・旧版ダウンロードの可用性。

本業の学校アカウント／Drive／スプレッドシートや、生徒情報と分離。権限最小化、バックアップ、記録の削除ルールを整備してから運用する。

## 6. GAS第一商品の価格を決めるまで

販売価格の決定前に、実在の未経験者が導入する時間、初回設定の難易度、採点から結果印刷までの所要時間、修正や問い合わせコスト、1団体ライセンスの対象人数を検証する。最低限以下を記録。
- セットアップ時間、途中で止まった箇所、ヘルプを必要とした回数。
- 得点入力ミス・同点・未入力・再計算・誤操作の復帰結果。
- PDF/紙印刷の実用性、別アカウントへの移管の成否。
- 導入サポートの必要時間、年間想定の保守負担。

価格は検証結果を踏まえた候補を比較してから定める。『GASだから安価』や『時短だから高額』とは決めない。
