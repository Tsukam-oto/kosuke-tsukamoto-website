# 余白 LYRIC NOTE — Mac・iPhone・iPadへの追加方法

## アプリURL
https://kosuke-tsukamoto-website.pages.dev/yohaku/

既存のクラウド保存・ログイン・歌詞ストックは変更しません。別のデータベースや別のサイトは作りません。各端末のアプリから同じユーザーでログインします。

## Mac
- Chromeで上記URLを開き、メニューから「キャスト、保存、共有」→「ページをアプリとしてインストール」を選ぶ。表示名は「余白」。
- Safariでは「ファイル」→「Dockに追加」。
- アプリとして開けるようになったらDockに固定。複数ブラウザで二重にインストールする必要はありません。

## iPhone／iPad
- SafariでURLを開き、共有 →「ホーム画面に追加」。
- 「Webアプリとして開く」がある場合は有効にして追加します。
- ホーム画面から初めて起動すると、Safari本体とは別にログインが必要な場合があります。

## 注意
- オフライン編集・オフライン同期は今回の対象外です。編集時はネット接続を確認してください。
- インストール操作は各端末で1回ずつ行います。
- 新アイコンが反映されない場合は、未同期の原稿がないことを確認してからホーム画面の旧アイコンを入れ直してください。クラウドにある歌詞を削除する必要はありません。
- 本更新は表示用アイコン・PWA設定だけです。同期できるかどうかの最終判断は複数端末での実機試験が必要です。
