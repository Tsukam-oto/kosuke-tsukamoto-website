## 製品設計の落とし穴

Google公式のコンテナバインドスクリプトでは、編集権限者やファイルをコピーした所有者がスクリプトを閲覧・編集できる。コードを隠せる前提でライセンスや価格を設計しない。
参考：https://developers.google.com/apps-script/guides/bound

BOOTHのダウンロード商品は過去に購入した商品を再ダウンロードできるが、販売者が旧ファイルを削除すると不可になる。版管理と過去購入者への連絡を必要に応じて設計する。
参考：https://booth.pixiv.help/hc/ja/articles/360009206893-
