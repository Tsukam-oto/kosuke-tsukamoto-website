# 商品パッケージ標準｜購入前と購入後の体験（案）

**下書き・未販売**。製品別の権利・仕様が確定するまで正式な利用条件として発行しない。

## 1. 楽譜商品

想定同梱物：README、総譜A4、必要なら指揮用A3、全パート譜、団体用利用許諾書、更新履歴。作品によって編成・ファイル構成は変わる。

- 商品ページ：正式題名、作詞作曲、編成、演奏時間と根拠、難易度と根拠、パート一覧、試聴、譜例、版、印刷方式、税込価格、団体内の許諾条件。
- 監査：Finale/MusicXML正本と全パートの音高・移調・リズム・休符・強弱・打楽器・小節順・譜めくりを照合。A4/A3実寸印刷して確認。
- 団体の指導者交代や年度をまたぐ利用は標準許諾に含める案。ただし本人が許諾できる権利に限定。動画・録音・編曲や大会の証明は別に確認。
- 発売前：作詞者の共同著作・職務・出版社/管理団体の委託範囲、学校との制作経緯、購入者への許諾の対象団体を確定。

## 2. GAS商品

想定同梱物：購入後にコピーして使用するSheetsテンプレート、架空データ、図解導入手引、GAS利用許諾書、更新履歴、問い合わせ先。

- 商品ページ：対応Googleアカウント・Google Workspace管理者の制限、初回認証と求める権限、端末とブラウザ、保存場所、機能制限、サポート期間、価格を表示。
- 受入試験：購入者相当の別アカウントがコードの貼付なしでコピー→初期設定→サンプル投入→集計→印刷→再起動→バックアップ/復元を実行。導入時間は**実測後**にだけ表示。
- 採点結果は購入者のDriveで管理し、販売者の私的アカウントに送信しない設計を、ソースと実機両方で確認。学校の名簿や実データをテストに使わない。
- コンテナバインドGASの購入者にはソースを読めることがあるため、コード閲覧不可と偽らず、同じ学校内の改変・引継ぎと別団体への再配布を契約上分ける。
- バージョン更新、Google側の仕様変更、ユーザーによる改変、初期導入不能時のサポート・返金規定を明文化。

## 3. BOOTHの再ダウンロードと版管理

公式ヘルプによれば、購入者はダウンロードファイルを再取得できるが、販売者が旧ファイルを削除すると旧版をダウンロードできない。原則旧版を保存し、版番号・変更履歴・移行案内を付与する。削除が必要なら購入者へ事前連絡し影響を検証する。

## 4. 個人購入と学校公費

先生が自費で買う場合の許諾主体（本人/所属校）、公費購入の契約主体（学校/設置者）を混同しない。転任、複数校合同、学校統廃合、教員の改変・引継ぎの扱いを商品に明示する。学校公費は見積・決裁・納品・請求を学校の規程に従って別経路で扱う。

## 5. 発売判定

権利、服務、品質、納品物、商品表示、顧客対応、個人情報、発注・返金、本人最終判断をすべて通過。草案・技術試験のみで有償販売を始めない。
